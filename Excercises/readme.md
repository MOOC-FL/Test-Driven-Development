> **"99% of the learning happens when doing the exercises."**

The prose chapters serve primarily to move concepts from *"unknown unknowns"* (things you don't know you don't know) to *"known unknowns"* (things you know you need to learn), so that the exercises can effectively build practical skill.


> **"During this course, I will not add any production code, unless it is required by a failing test."**

This statement reflects a strict adherence to the **TDD Red-Green-Refactor** cycle:
- **Red** — Write a failing test first
- **Green** — Add the minimal production code to make it pass
- **Refactor** — Improve the code while keeping tests green

####  No production code is written without a failing test to justify its existence.
