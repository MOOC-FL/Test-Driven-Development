
## Applications of A/B Testing

| Domain | Purpose / Context | Examples / Key Details |
| :--- | :--- | :--- |
| **Online Social Media** | Understand user engagement and satisfaction with online features (e.g., new features or products). | Used by **LinkedIn, Facebook, Instagram**. Also used for complex experiments on network effects, offline user behavior, and user influence on one another. |
| **E-commerce** | Improve the purchase funnel; even marginal decreases in drop-off rates can significantly increase sales. | Testing elements such as **copy text, layouts, images, and colors**. Users see only one of two versions to determine preference. |
| **Product Pricing** | Determine the optimal price point for a new product or service to maximize total revenue. | Particularly effective for **digital goods**. Helps solve one of the most difficult challenges in product launch. |
| **Political Campaigns** | Garner online attraction and understand voter preferences. | **Barack Obama's 2007 presidential campaign** tested four different buttons and six accompanying images for newsletter signups. |
| **HTTP Routing / API Feature Testing** | Limit customer exposure to new backend versions; route only a percentage of traffic to a newer version for safety. | An **HTTP layer 7 reverse proxy** routes `n%` of traffic to the newer backend instance and `100-n%` to the stable older version. If bugs exist, only `n%` of users are affected. |
