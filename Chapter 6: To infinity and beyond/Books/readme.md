### Recommended Reading Order for the alameensoft Role

Given the job requirements (**C++/C#, MFC, SQL Server, OOP, debugging**), here is a prioritized sequence:

| Priority | Book | Why for this role |
| :--- | :--- | :--- |
| **1** | *Clean Code* | Directly impacts daily code quality. The ERP desktop app will have many legacy modules — clean, readable code reduces bugs. |
| **2** | *TDD by Example* | Even if the company doesn't use TDD strictly, the habit of writing testable code improves modularity (critical for C++/C# maintenance). |
| **3** | *Four Rules of Simple Design* | Very short but powerful. Helps resist over-engineering — important for Windows desktop ERP features with tight deadlines. |
| **4** | *Growing OO Software* | Mock objects help unit test database (SQL Server) and UI (MFC) dependencies without real connections or windows. |
| **5** | *Continuous Delivery* | The job lists CI/CD as a *plus*. Understanding pipelines will set you apart, especially for automated builds in Git/TFS. |
